## III. GENERAL REQUIREMENTS

### 1. Research and Architecture:

#### Conduct a thorough investigation into the assigned topic.

#### Clearly define the System Architecture before writing code. Utilize UML

#### diagrams or modern architecture charts.

#### Use reliable academic and official documentation sources. Include examples,

#### strengths, weaknesses, and a comparative analysis with alternative

#### technologies.

### 2. Demonstration Website:


#### Develop a fully functional website applying the assigned technology.

#### The application should follow modern UI/UX principles.

#### Ensure the project structure is logical and strictly follows the MVC or

#### component-based paradigms.

### 3. Writing and Presentation:

#### The report must be structured logically: Introduction, Theoretical Survey,

#### Requirement Analysis, System Design, Results & Discussion, and Conclusion.

#### Utilize proper grammar, IEEE citation format, and professional technical

#### language.

## IV. REQUIREMENTS FOR OUTPUT

#### Complete Report Word & PDF Must adhere to the Faculty of Information

#### Technology's official template. Avoid AI-generated padding; focus on concise,

#### technical analysis.

#### Source Code & Repository: Provide a link to a public/private GitHub repository

#### containing the complete, well-documented source code and dependency file.

#### Product Presentation Video:

#### Duration: Maximum 15 minutes.

#### Content: Cover theoretical aspects, architectural design, and a live

#### demonstration of the codebase and application.

#### Participation: All team members must actively speak and present.

#### README.md: Include a markdown file in the root directory with step-by-step

#### setup instructions, environment variables template, and testing credentials.
