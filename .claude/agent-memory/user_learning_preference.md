User đang học môn Web Programming & Applications (503073). Khi làm midterm/lab, user ưu tiên:

- **Cân bằng giữa học sâu công nghệ và điểm số** — không cần tối đa 10/10 nếu phải hi sinh việc hiểu bản chất
- **Hiểu trade-off** thay vì chỉ copy code chạy được — thích đọc pros/cons trước khi quyết định
- **Hỏi để chốt decisions** trước khi code, không thích assistant tự đoán
- **Giao tiếp bằng tiếng Việt** trong conversation, code và file có thể mix tiếng Việt + Anh

**How to apply:**
- Khi gợi ý giải pháp: trình bày 2-3 option với pros/cons, kèm recommendation có justification — không chỉ đưa 1 đáp án
- Khi giải thích code: bao gồm "why" thay vì chỉ "what"
- Khi đề xuất feature mới: cân nhắc effort/learning ratio thay vì cứ đẩy max scope
- Default trả lời tiếng Việt, trừ khi user yêu cầu khác (vd: viết report/video tiếng Anh do penalty)
